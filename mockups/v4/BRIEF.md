## Grammar and fingerprint
Gallery/catalog: object first, factual labels, jump index, horizontal native collection rail, quiet inquiry plate. Filmic one-shot would obstruct browsing; chaptered editorial would overemphasize prose; live surface is for software; continuous world needs geography/heavy assets; typographic poster contradicts discreet titles; split stage invents a comparison; rhythmic cutlist would overwhelm this quiet collection.

Against v1/v2: differs in grammar, object-index navigation, layered-photo hero, sequence, inquiry-plate ending and signature. V3 was inspected read-only from origin/main after its concurrent publication: v4 differs in object-index navigation, native horizontal range sequence, inquiry-plate close, and the separating-studies/event-resolution signature (4/6); both share photographic perspective and a minimal gallery-adjacent visual family. This isolated task has no previous scroll-craft registry.

## Journey and feeling curve
1. Curiosity: room photography in a large plane, a closer product study in front.
2. Agency: a native horizontal rail exposes the actual rental categories.
3. Intimacy: one quiet chair, its existing published material facts.
4. Delight (the one peak): furniture study planes move outward as the event photograph grows into a complete setting.
5. Resolve: a stable inquiry plate offers a local quote preview.

## Score and layer contract
| Beat | Device | Purpose |
|---|---|---|
| Room | Natural-flow differential parallax | Rear room plane drifts slowly; near product study travels farther |
| Range | Native horizontal pan | Real category controls; keyboard focus scrolls each item into view |
| Chair | CSS perspective / scroll rotation | A photographed study gently changes angle, never claims a 3D product model |
| Setting | Sticky scene, reveal, depth | Largest travel; side studies separate and the real event resolves |
| Inquiry | Static flow | All content remains visible; ends in an action |

Hero layers are intentionally framed photography, not extracted furniture pretending to be a reconstructed room. Separate photograph boundaries make their contact relation honest; no false alpha, duplicates or holes. Semantic text stays on white, outside the photographs. Opening shows the room and near study; midpoint separates their rates; exit clears into the category index. Mobile uses a full-width room and a smaller offset study. No pointer capture, custom cursor, scroll interception, WebGL or video. rAF only runs on scroll/resize/visibility events; no ambient loop. Reduced motion removes position changes and extra sticky travel.

## Approved direction change: more spectacular v4
The user liked v4 but requested a substantial redesign with much more motion and visual impact. This revision replaces the original natural-flow opening and one event reveal with two coordinated photographic scenes. It is still v4, with rollback available in git.

New curve: curiosity (layered photographic installation) → immersion (the surrounding studies leave and the room expands) → choice (native category rail) → intimacy (chair study in perspective) → delight (three real events move through a dark photographic gallery) → resolve (still inquiry plate). The gallery is the longest scene at 300vh desktop; the opening is 245vh. Mobile shortens the hero to 190svh and converts the gallery to a vertical photographic sequence with mild perspective, eliminating the long pinned horizontal journey.

New signature: the room opens out of a three-plane photographic installation, then the page changes to a walk past complete event photographs. All planes are clearly framed photographs, not fabricated cutout room geometry. Title and action occupy a separate stable white plane. Desktop gallery focus scrolls the relevant card into view; native wheel/touch behavior is not prevented. Pause is a persistent per-session user choice across the seven v4 pages; system reduced motion takes priority. No loops, video, generated imagery or new third-party execution.

Device score: pinned perspective hero / native horizontal category pan / natural-flow chair rotation / scroll-driven horizontal gallery with per-panel perspective and scale / static inquiry. At smaller widths the gallery becomes natural vertical flow. Existing navigation, typography limits, quotations and data boundaries remain.

## Current direction supersedes the cinematic redesign
The user rejected the spectacle-focused direction and requested modernization without losing Lavish's essence. SOURCE-AUDIT.md records the required actual-site review. The current implementation preserves the site's category-sidebar/content pairing and white product showroom, replaces pinned scenes with native flow, and uses the original imagery, logo, yellow detail and factual product information. The prior motion score and novelty claims above describe earlier revisions only. The user's latest direction takes precedence over the upstream skill's preference for multiple motion families. Scroll-craft's authentic-brand research, typography restraint, mobile composition and accessible fallback principles continue to apply; no unfamiliar scripts were executed.
